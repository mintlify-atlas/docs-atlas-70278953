VibeVoice is a family of open-source frontier voice AI models. This guide gets you from zero to a working demo as fast as possible. Choose the path that matches your goal:

- **ASR path** — transcribe long-form audio with speaker diarization and timestamps
- **Realtime TTS path** — stream text and hear synthesized speech in ~200 ms

## Prerequisites

<Warning>
VibeVoice requires a CUDA-capable NVIDIA GPU. CPU-only inference is not supported. An NVIDIA T4 or better is recommended for real-time TTS performance.
</Warning>

- Python 3.9 or higher
- NVIDIA GPU with CUDA support
- Docker (strongly recommended for managing the CUDA environment)
- `git` and `ffmpeg` installed on your system

## Installation

<Steps>
  <Step title="Launch the NVIDIA PyTorch container">
    Using the official NVIDIA Deep Learning Container ensures a consistent CUDA environment and avoids driver compatibility issues.

    <Tabs>
      <Tab title="ASR">
        ```bash
        # NVIDIA PyTorch Container 24.07–25.12 verified
        sudo docker run --privileged --net=host --ipc=host \
          --ulimit memlock=-1:-1 --ulimit stack=-1:-1 \
          --gpus all --rm -it \
          nvcr.io/nvidia/pytorch:25.12-py3
        ```
      </Tab>
      <Tab title="Realtime TTS">
        ```bash
        # NVIDIA PyTorch Container 24.07 / 24.10 / 24.12 verified
        sudo docker run --privileged --net=host --ipc=host \
          --ulimit memlock=-1:-1 --ulimit stack=-1:-1 \
          --gpus all --rm -it \
          nvcr.io/nvidia/pytorch:24.07-py3
        ```
      </Tab>
    </Tabs>

    <Note>
      If your container does not include Flash Attention, install it manually after the container starts:
      ```bash
      pip install flash-attn --no-build-isolation
      ```
    </Note>
  </Step>

  <Step title="Clone the repository">
    ```bash
    git clone https://github.com/microsoft/VibeVoice.git
    cd VibeVoice
    ```
  </Step>

  <Step title="Install the package">
    <CodeGroup>
      ```bash ASR
      # Base install — includes all ASR dependencies
      pip install -e .
      ```
      ```bash Realtime TTS
      # Streaming TTS extras pin transformers==4.51.3 for compatibility
      pip install -e .[streamingtts]
      ```
    </CodeGroup>

    <Tip>
      The `[streamingtts]` extra pins `transformers==4.51.3`. If you plan to use both ASR and Realtime TTS in the same environment, install the base package first and check compatibility before adding the extra.
    </Tip>
  </Step>
</Steps>

## Try VibeVoice

<Tabs>
  <Tab title="ASR — Speech Recognition">
    VibeVoice-ASR (7B) transcribes up to 60 minutes of audio in a single pass, producing structured output with speaker labels, timestamps, and content.

    <Steps>
      <Step title="Install ffmpeg (required for the demo)">
        ```bash
        apt update && apt install ffmpeg -y
        ```
      </Step>

      <Step title="Run the Gradio demo">
        This launches a browser-based interface where you can upload audio files and inspect rich transcriptions.

        ```bash
        python demo/vibevoice_asr_gradio_demo.py \
          --model_path microsoft/VibeVoice-ASR \
          --share
        ```

        The `--share` flag generates a public Gradio URL so you can access the demo from any browser, including outside the Docker container.

        <Note>
          The model weights (~7B parameters) are downloaded from Hugging Face on first run. Ensure you have sufficient disk space and a stable internet connection.
        </Note>
      </Step>

      <Step title="Run inference directly from an audio file">
        Skip the UI and transcribe a file from the command line:

        ```bash
        python demo/vibevoice_asr_inference_from_file.py \
          --model_path microsoft/VibeVoice-ASR \
          --audio_files /path/to/your/audio.wav
        ```

        The output is a structured transcription containing who spoke, when, and what was said.
      </Step>
    </Steps>

    **What VibeVoice-ASR produces:**

    | Field | Description |
    |---|---|
    | Who | Speaker label for each segment |
    | When | Start and end timestamps |
    | What | Transcribed text content |

    The model supports over 50 languages natively — no explicit language setting required. You can also supply custom hotwords to improve accuracy on domain-specific terms.

    <Warning>
      VibeVoice-ASR is intended for research and development only. Do not deploy in production without further testing. Always disclose when content was generated or processed by AI.
    </Warning>
  </Tab>

  <Tab title="Realtime TTS — Streaming Synthesis">
    VibeVoice-Realtime-0.5B is a lightweight (0.5B parameter) TTS model with ~200 ms first-audio latency and streaming text input support.

    <Steps>
      <Step title="Launch the real-time WebSocket demo">
        ```bash
        python demo/vibevoice_realtime_demo.py \
          --model_path microsoft/VibeVoice-Realtime-0.5B
        ```

        <Note>
          NVIDIA T4 and Mac M4 Pro achieve real-time performance in testing. Weaker devices may require speed optimizations. Network latency can add to the perceived time before audio playback begins, beyond the ~200 ms generation latency.
        </Note>

        Alternatively, try the hosted notebook without any local setup:

        [![Open in Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/microsoft/VibeVoice/blob/main/demo/vibevoice_realtime_colab.ipynb)
      </Step>

      <Step title="Run inference from a text file">
        Example text files are provided under `demo/text_examples/`:

        ```bash
        python demo/realtime_model_inference_from_file.py \
          --model_path microsoft/VibeVoice-Realtime-0.5B \
          --txt_path demo/text_examples/1p_vibevoice.txt \
          --speaker_name Carter
        ```
      </Step>

      <Step title="(Optional) Download experimental multilingual voices">
        Nine additional languages are available for exploration: German, French, Italian, Japanese, Korean, Dutch, Polish, Portuguese, and Spanish.

        ```bash
        bash demo/download_experimental_voices.sh
        ```

        <Warning>
          Multilingual voices have not been extensively tested. The model is primarily built for English; other languages may produce unpredictable results. Use with caution.
        </Warning>
      </Step>
    </Steps>

    **Key specs:**

    | Property | Value |
    |---|---|
    | Parameters | 0.5B |
    | First audio latency | ~200 ms (hardware dependent) |
    | Max generation length | ~10 minutes (8k context window) |
    | Speakers | Single speaker (English) |
    | Frame rate | 7.5 Hz acoustic tokenizer |

    <Warning>
      VibeVoice-Realtime is intended for research and development only. High-quality synthetic speech can be misused for impersonation or disinformation. Always disclose AI-generated content and comply with applicable laws.
    </Warning>
  </Tab>
</Tabs>
