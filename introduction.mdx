## What is VibeVoice?

VibeVoice is a family of open-source frontier voice AI models from Microsoft Research, covering both **Text-to-Speech (TTS)** and **Automatic Speech Recognition (ASR)**. The models are built around a core innovation: continuous speech tokenizers operating at an ultra-low frame rate of **7.5 Hz**, enabling efficient processing of long audio sequences while preserving fidelity.

VibeVoice employs a [next-token diffusion](https://arxiv.org/abs/2412.08635) framework that combines a Large Language Model (LLM) to understand textual context with a diffusion head to generate high-fidelity acoustic details.

  <Card title="VibeVoice-ASR" icon="microphone" href="/models/vibevoice-asr">

</CardGroup>

## Key Capabilities

<CardGroup cols={2}>
  <Card title="60-minute single-pass ASR" icon="clock">
    Process up to 60 minutes of continuous audio within a 64K token context window, maintaining speaker consistency and semantic coherence.
  </Card>
  <Card title="Rich transcription output" icon="list">
    Jointly performs ASR, speaker diarization, and timestamping — producing structured output of who said what and when.
  </Card>
  <Card title="Real-time streaming TTS" icon="signal-stream">
    Start generating speech from the first tokens of text input, enabling seamless integration with streaming LLM outputs.
  </Card>
  <Card title="Multilingual support" icon="globe">
    ASR supports 50+ languages natively with code-switching. TTS covers English, Chinese, and experimental multilingual voices.
  </Card>
  <Card title="LoRA fine-tuning" icon="sliders">
    Fine-tune VibeVoice-ASR on custom domains with Low-Rank Adaptation using provided training scripts.
  </Card>
  <Card title="vLLM deployment" icon="server">
    Deploy ASR as a high-performance OpenAI-compatible API using the included vLLM plugin — no source modifications required.
  </Card>
</CardGroup>
