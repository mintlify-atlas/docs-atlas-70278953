**VibeVoice-Realtime-0.5B** is a lightweight real-time text-to-speech model built for streaming text input and low-latency audio output. It produces the first audible audio chunk in approximately **~200 milliseconds** and supports robust long-form speech generation up to ~10 minutes from an 8K context window.

## What It Does

VibeVoice-Realtime enables use cases where the first word of audio must arrive before the full text is known:

- **LLM voice interfaces** — start speaking from the LLM's first output tokens, before the full answer is generated
- **Live narration** — narrate streaming data feeds or subtitles with minimal delay
- **Real-time TTS services** — serve audio over WebSocket with sub-second response

## Architecture

### Interleaved Windowed Design

VibeVoice-Realtime uses an **interleaved, windowed** design that enables streaming:

1. Incoming text is encoded in **incremental chunks** as new tokens arrive.
2. In parallel, the diffusion-based acoustic latent generation continues from prior context — it does not wait for the full text.
3. Each window of text produces a corresponding window of audio latents, which are decoded and streamed to the output.

This interleaved approach is what achieves the ~200 ms first-chunk latency: audio generation begins after the very first text window is processed.

### Acoustic Tokenizer Only (No Semantic Tokenizer)

Unlike VibeVoice-TTS-1.5B, the Realtime variant removes the semantic tokenizer entirely. Only the **acoustic tokenizer** (64-dim latent, 7.5 Hz) is used.

| Component | VibeVoice-TTS-1.5B | VibeVoice-Realtime-0.5B |
|---|---|---|
| Acoustic tokenizer (7.5 Hz) | Yes | Yes |
| Semantic tokenizer (7.5 Hz) | Yes | **No** |
| LLM backbone | Qwen2.5-1.5B | Qwen2.5-0.5B |
| Diffusion head | Yes | Yes |
| Multi-speaker | Up to 4 | Single speaker |
| Streaming input | No | Yes |

Removing the semantic tokenizer reduces both model size and per-step latency, at the cost of multi-speaker capability and some acoustic richness.

The decoder layers are split: lower Transformer layers encode text only, while upper layers (`tts_backbone_num_hidden_layers = 20`) jointly encode text and generate speech. This split allows text encoding to proceed ahead of audio generation.

## Limitations

<Warning>
  **English-primary model.** Transcripts in languages other than English may produce unexpected audio output. The nine multilingual experimental speakers are provided for exploration only and have not been thoroughly validated.
</Warning>

| Limitation | Detail |
|---|---|
| Single speaker only | No multi-speaker support. Use VibeVoice-TTS-1.5B for multi-speaker generation. |
| No background music/noise | The model synthesizes speech only. Background music, sound effects, and ambient noise are not supported. |
| Short input instability | Inputs of 3 words or fewer may produce degraded or unstable output. |
| No code or formulas | Mathematical formulas, code snippets, and uncommon symbols should be pre-processed or removed before passing to the model. |
| Research only | Not recommended for commercial or real-world deployment without further testing. |
