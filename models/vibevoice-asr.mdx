**VibeVoice-ASR-7B** is a unified speech-to-text model that handles up to 60 minutes of continuous audio in a single pass, producing structured transcriptions with speaker attribution, timestamps, and content — all jointly in one inference call.

## What It Does

VibeVoice-ASR performs three tasks simultaneously in a single forward pass:

- **Who** — Speaker diarization: which speaker said each segment
- **When** — Timestamping: when each segment starts and ends
- **What** — ASR: the transcribed text content

This joint approach avoids the error accumulation that occurs when running separate ASR, diarization, and alignment pipelines in sequence.

## Key Features

<AccordionGroup>
  <Accordion title="60-Minute Single-Pass Processing">
    Unlike conventional ASR models that slice audio into short chunks (typically 30 seconds), VibeVoice-ASR accepts up to **60 minutes** of continuous audio within a 64K token context window. Global context is preserved across the entire recording, ensuring consistent speaker tracking and semantic coherence throughout an hour-long meeting or interview.
  </Accordion>
  <Accordion title="Customized Hotwords">
    Users can supply domain-specific hotwords — proper names, technical terminology, or product names — that guide the recognition process. This significantly improves accuracy on specialized content where out-of-vocabulary terms would otherwise be misrecognized.
  </Accordion>
  <Accordion title="Rich Transcription (Who / When / What)">
    The model jointly performs ASR, diarization, and timestamping in a single pass. Output is a structured transcript indicating which speaker said what and at what time, without requiring a separate alignment step.
  </Accordion>
  <Accordion title="50+ Languages with Code-Switching">
    VibeVoice-ASR natively supports over 50 languages with no explicit language selection required. It also handles code-switching — mid-utterance transitions between languages — within and across speakers.
  </Accordion>
</AccordionGroup>

## Architecture

VibeVoice-ASR-7B is built on a Qwen2.5-7B decoder and uses two continuous speech tokenizers:

- **Acoustic tokenizer** — encodes raw waveform details into a 64-dimensional continuous latent, operating at **7.5 Hz**
- **Semantic tokenizer** — encodes higher-level linguistic content into a 128-dimensional continuous latent, also at **7.5 Hz**

The ultra-low 7.5 Hz frame rate is the key to fitting 60 minutes of audio within the model's 64K token context window. At this rate, one hour of audio produces roughly 27,000 frames — well within budget.

The decoder autoregressively generates structured text from these audio representations. There is no diffusion head; generation is purely text-autoregressive over speaker labels, timestamps, and transcribed words.

  VibeVoice-ASR was integrated into Hugging Face Transformers in v5.3.0 (released 2026-03-06), enabling direct use via the `transformers` library.
</Note>

## Evaluation Results

## Language Distribution

VibeVoice-ASR supports **50+ languages** with no explicit language selection needed. The model automatically detects the spoken language and can handle code-switching within utterances. Coverage includes major European, Asian, and other world languages. Refer to the [language distribution chart](https://github.com/microsoft/VibeVoice/blob/main/Figures/language_distribution_horizontal.png) in the repository for the full breakdown.

## LoRA Finetuning

LoRA (Low-Rank Adaptation) finetuning is supported for domain adaptation. This allows you to adapt the model to specialized vocabularies, accents, or recording conditions without full fine-tuning.

<Tip>
  The finetuning code is available in the [finetuning-asr](https://github.com/microsoft/VibeVoice/tree/main/finetuning-asr) directory of the repository.
</Tip>

## vLLM Inference

For high-throughput production deployments, VibeVoice-ASR supports vLLM for faster inference with continuous batching.
